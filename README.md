# MySQL-Assignment-2-Clauses-and-Joins

This assignment focuses on querying and analysing employee data using MySQL. It involves retrieving distinct values, filtering records using conditions, sorting and grouping data, and applying aggregate functions such as SUM, MIN, MAX and AVG. It also explores the use of HAVING clauses and different types of joins (INNER JOIN, LEFT JOIN and RIGHT JOIN) to combine data from multiple tables and extract meaningful information.
